# ffmpeg-converter

A browser-based media converter powered by FFmpeg WebAssembly (via `@ffmpeg/ffmpeg`). Built with Vue 3 and Vite.

## Usage

```bash
npm install
npm run dev
```

Open the provided local URL in your browser, upload a media file, choose output format, and convert — all client-side.

## Build

```bash
npm run build
npm run preview
```
